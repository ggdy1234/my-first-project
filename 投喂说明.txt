=====================================================
  WorkBuddy · 温柔成长工作台 —— 投喂说明
=====================================================

【一句话介绍】
一个马卡龙配色、圆角卡片、温柔女性化的个人成长PWA工作台，
统一管理工作、生活、财务、阅读、运动、口才、心情、京剧自媒体、热点、复盘。

【文件清单与用途】
┌──────────────┬──────────────────────────────────────┐
│ 文件         │ 用途                                 │
├──────────────┼──────────────────────────────────────┤
│ index.html   │ 全部页面结构（12个模块）            │
│ styles.css   │ 马卡龙主题样式（圆角/阴影/配色）   │
│ app.js       │ 全部交互逻辑 + 本地数据存储        │
│ manifest.json│ PWA配置，支持安装到手机桌面        │
│ icons/       │ 应用图标                           │
│ README.md    │ 功能说明文档                       │
└──────────────┴──────────────────────────────────────┘

【12个功能模块一览】
  ① 首页概览  — 日期问候/进度/三件事/时间轴/快捷打卡/周摘要/鼓励语
  ② 每日计划  — 增删改查/优先级/分类/固定行程/完成率圆环
  ③ 运动管理  — 体重曲线/运动记录/周目标/日历打卡/连续天数
  ④ 存钱计划  — 收入记录/学费目标(骐宝+知烨)/多目标/进度条
  ⑤ 阅读记录  — 书架/进度/笔记/年度统计
  ⑥ 日日精进  — 想法输入→概括+金句+衍生思考+行动指导
  ⑦ 口才训练  — 话术模板(自我介绍/商务/直播)/即兴每日一题/30秒计时/录音复盘
  ⑧ 京剧视频  — 内容生成/选题建议/草稿箱/11:30自动生成
  ⑨ 热点新闻  — 热搜/医疗医保热点/政策解读/10:30推送
  ⑩ 心情日记  — 6种心情/感恩三件事/热力图/趋势图
  ⑪ 习惯打卡  — 7个默认习惯/自定义/打卡动画/月度完成率
  ⑫ 每周复盘  — 自动汇总/满意度/改善项

【口才·表达训练 详细说明】
  · 话术模板：分"自我介绍/商务沟通/直播开场/自定义"四类
    → 内置6条示例话术，可复制、编辑、删除、新建
    → 点击"复制"一键复制到剪贴板
  · 即兴练习：每日一题（如"30秒介绍我的工作台"）
    → "换一题"随机抽题，"开始计时"启动30秒倒计时
    → 计时结束自动提示，点"完成练习"记录今日打卡
  · 复盘录音：调用麦克风录制练习音频
    → 录完可填写"改进点"，保存后出现在录音列表
    → 支持播放回听（需HTTPS或localhost环境）
  · 首页"口才"快捷打卡 → 一键跳转到口才页面
  · 首页每周摘要新增"口才练习"统计位
  · 每周复盘新增"口才训练"板块

【使用方法】
  手机端：用浏览器打开 index.html → 分享 → 添加到主屏幕
  电脑端：双击 index.html 直接用浏览器打开
  无网络也可使用（纯静态+localStorage）

【投喂给WorkBuddy时的提示词建议】
  "请帮我打开 workbuddy 文件夹中的 index.html，
   启动一个本地服务器，并告诉我如何在手机上预览。
   然后根据我的反馈逐步优化界面和交互。"
