# WorkBuddy · 水系温柔成长伙伴 v3

> 一个温柔的自我成长空间，每天一点点，就够了。

## 功能模块（11 个全部内置）

| 模块 | 说明 |
|---|---|
| 📅 黄历宜忌 | 首页顶部卡片，宜绿忌粉，按日期种子轮换，联动方位建议 |
| 🎂 生日提醒 | 灵活添加/删除，支持公历农历，提前N天高亮，当天弹窗祝福 |
| 💧 水珠存钱 | 颜色按规则自动分配（蜜桃橙/薰衣草紫/浅粉/奶油金），饱满度随存入变化 |
| 🌊 学费溪流 | 骐宝+知烨合并一条溪流，水位随存入上涨，月均摊提示 |
| 🎨 水系配色 | 5个时段自动切换（清晨雾蓝→深夜月光白），不用你选 |
| 🍅 番茄钟 | 打卡后引导25分钟专注，铃响温柔提醒喝水休息 |
| 📊 财务重构 | 收入/支出/存钱/结余四栏清晰，明细可展开 |
| 🧘 精进四步 | 概括→三种金句→延展思考→明天就做的行动 |
| 🔥 热点精选 | 财经/医保稽核/立项指南/精选，手动刷新轮换 |
| 📜 月度复盘 | 三封信（给过去/现在/未来自己），不审问不检讨 |
| 🌙 每周小憩 | 周日自动弹出，只问三件小事，不卷 |

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构（7 Tab 导航 + 全部 11 模块） |
| `styles.css` | 水系流动配色 + 水珠动画 + 溪流动画 + 时段变色 |
| `app.js` | 全部交互逻辑（黄历库/生日/水珠/学费/番茄钟/精进/热点/复盘/小憩） |
| `icon.svg` | 水波纹桌面图标（雾蓝→薄荷绿渐变） |
| `icon-192.svg` | 192x192 备用图标 |
| `manifest.json` | PWA 桌面配置 |
| `README.md` | 本说明文档 |

## 使用方式

1. 将整个文件夹上传到 GitHub 仓库（覆盖旧文件）
2. 确认 Settings → Pages：Source = main / root
3. 等 2 分钟构建完成
4. 快捷指令打开 URL：`https://你的用户名.github.io/仓库名/`
5. 分享 → 添加到主屏幕
