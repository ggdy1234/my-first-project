# WorkBuddy · 温柔成长工作台

> 一个为女性设计的、马卡龙配色的个人成长管理平台

## 🌸 功能模块

| 模块 | 功能 |
|------|------|
| 🏠 首页 | 日期问候、完成进度、三件事、时间轴、快捷打卡、每周摘要、鼓励语 |
| 📋 计划 | 任务增删改查、优先级、分类筛选、固定行程、完成率圆环 |
| 🏃 运动 | 体重曲线、运动记录、周目标、日历打卡、连续天数 |
| 💰 财务 | 收入记录、学费目标（骐宝+知烨）、多存钱目标、进度条 |
| 📚 阅读 | 书架管理、阅读进度、读书笔记、年度统计 |
| 🌱 精进 | 想法输入 → 智能分析（概括+金句+衍生思考+行动指导） |
| 🎭 京剧 | 内容生成、选题建议、草稿箱、11:30自动生成 |
| 📰 新闻 | 热搜列表、医疗医保热点、政策解读、10:30推送 |
| 💖 心情 | 6种心情选择、感恩三件事、日记、热力图、趋势图 |
| ✅ 习惯 | 7个默认习惯、自定义、打卡动画、月度完成率 |
| 🔄 复盘 | 自动汇总周数据、满意度/改善项记录 |

## 📱 使用方式

1. 用手机浏览器打开 `index.html`
2. iOS：Safari → 分享 → 添加到主屏幕
3. Android：Chrome → 菜单 → 安装应用
4. 即可像原生App一样使用

## 🎨 设计特点

- 马卡龙配色：奶油白、浅粉、蜜桃橙、薰衣草紫、薄荷绿、雾蓝
- 大圆角卡片 + 柔和阴影 + 充足留白
- 数据本地存储（localStorage），隐私安全
- 支持深浅色、适配手机/电脑
- 首次进入有引导页和示例数据

## 📂 文件结构

```
workbuddy/

```
