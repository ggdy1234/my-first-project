# WorkBuddy · 水系温柔成长伙伴

一个为女性设计的、马卡龙水色系的 iPhone 个人成长管理平台。

## 功能模块

| Tab | 内容 |
|---|---|
| 🏠 首页 | 日期问候 / 三件事 / 时间轴 / 快捷打卡 / 鼓励语 / 本月摘要 / 每周小憩 |
| 📋 计划 | 每日计划 + 固定行程 + 习惯打卡 |
| 💰 财务 | 收入/支出/存钱/结余 + 学费预存溪流 + 多目标水珠存钱 |
| 🏃 健康 | 运动管理 + 体重曲线 + 心情日记 |
| 🧘 精进 | 想法输入 → 概括/金句/衍生/行动四步 |
| 🔥 热点 | 财经 + 医保稽核 + 立项指南 + 精选热点 |
| 📊 复盘 | 自然月复盘（三封信：过去/现在/未来） |

## 特色设计

- **水系幸运色**：清晨雾蓝、上午薰衣草紫、午后蜜桃橙、傍晚薰衣草、深夜深雾蓝，随时间自动流转
- **对话式引导**：每天只问你一句"今天想先完成哪一件？"
- **25 分钟番茄钟**：专注结束自动提示喝水休息
- **存钱水珠**：每项目一滴水珠，颜色按用途自动分配（应急=蜜桃橙/旅游=薰衣草紫/学习=浅粉/心愿=奶油白金边），存入越多水珠越饱满
- **学费溪流**：骐宝+知烨合计一条溪流，水位随存入上涨
- **黄历宜忌**：每日自动显示宜忌 + 喜神财神方位 + 联动今日任务建议
- **生日提醒**：灵活添加/删除，支持公历农历，提前 N 天提醒，生日当天弹出温柔提示
- **月度复盘**：每月 1 号自动提示，三封信形式呈现
- **每周小憩**：周日弹出温柔卡片，跟自己待一分钟

## 部署方式

和之前一样：上传到 GitHub 仓库 → Settings → Pages → main / root → Save → 用快捷指令打开 URL 钉到桌面。

## 数据说明

所有数据存在手机 Safari 的 localStorage 本地，不上传任何服务器。
清除 Safari 网站数据会导致记录丢失，请勿手滑。

## 设计理念

不急、不卷、不逼自己。每天一点点，就够了。
